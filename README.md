Projeto desenvolvido em JavaScript com foco em Programação Orientada a Objetos (POO), inspirado no universo do dorama Alquimia das Almas.
O projeto simula uma batalha entre personagens diretamente no console do navegador.

👉 Abra o arquivo index.html e pressione F12 para acompanhar a batalha.

Personagens
🛡️ Jang Uk (Guerreiro) → alto dano e defesa com armadura
🔮 Naksu (Mago) → usa mana para atacar e curar
🏹 Dang-gu (Arqueiro) → ataque à distância com chance de crítico

Tecnologias utilizadas
JavaScript (ES6+)
HTML5
Programação Orientada a Objetos (POO)
